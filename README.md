# R15 → R6 animation retargeter

Convert Roblox R15 animations to R6.

Add to your `wally.toml`:

```toml
[dependencies]
retarget_r15_to_r6 = "revvy02/retarget-r15-to-r6@0.1.0"
```

Then install:

```sh
wally install
```

Require `Packages.retarget_r15_to_r6` in your project.
